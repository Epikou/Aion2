# AION 2 — Guide de groupe PvE

Guide de référence (Global EU, octobre 2026) pour un groupe de 3 joueurs PvE : Templar (tank), Assassin (DPS), Chanteur (soutien).

Site : https://epikou.github.io/Aion2/

## Contenu
Leveling 1→45, classes et synergies, donjons, routine quotidienne/hebdomadaire (checklists par joueur, planificateur de semaine), économie, récolte, Abîme, guilde, ailes. Recherche globale avec `Ctrl+K`.

## Fiabilité des données
Chaque donnée porte un badge : **Vérifié** (recoupée, avec date), **Non confirmé** (source unique ou non recoupée) ou **Écart** (sources en désaccord). Le jeu est sorti le 5 octobre 2026 : les valeurs peuvent évoluer avec les patchs, le compteur en jeu fait foi. Le reset hebdomadaire est affiché mercredi 16h00, heure de Paris.

## Utilisation en local
Ouvrir `index.html` dans un navigateur (aucun serveur requis). La progression est enregistrée dans le navigateur (localStorage), par profil.

## Structure
- `index.html` — point d'entrée
- `js/core.js` — routeur, stockage, temps, composants
- `js/pages/` — une page par section
- `data/` — checklists et images officielles (Steam)
- `css/style.css` — thèmes sombre et clair

Projet non officiel, sans lien avec NCSOFT. Images : captures officielles chargées depuis le CDN Steam.
